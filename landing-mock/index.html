How the algorithm works

Every recommendation is a trade-off, made explicit.

Nearest-station routing ignores queues, plug power and what you'll do for 25 minutes. DwellCharge scores each candidate on four criteria, reweights them for your situation, and plans the time you spend plugged in.

Context-aware engine

Multi-criteria scoring, weighted by context

Each station gets a normalized 0–1 value per criterion. Weights shift with context: at 12% battery, distance outweighs amenities; on a rainy evening, covered parking and short walks rank higher.

Architecture & API

Four live feeds in, one ranked list out.

Streams from mapping, routing, charger status and POI providers are normalized into one feature store. The forecaster and ranker read from it on every request, so answers reflect the last 30 seconds.
